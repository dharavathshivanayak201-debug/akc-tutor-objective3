# Code-availability wording

The wording below describes the public release without implying that every source dataset or trained checkpoint is distributed. Use it after checking the final repository and selecting the commit that accompanies the submitted manuscript.

## Suggested manuscript statement

> Code and supporting research artifacts for Objective 3 (AKC-Tutor), including the five phase notebooks, saved aggregate results, deterministic tutoring-response records, anonymized response ratings, plotting scripts and saved-output verification tools, are available at https://github.com/dharavathshivanayak201-debug/akc-tutor-objective3. The repository documents data provenance, implementation discrepancies and reproduction limitations. Learner-level educational prediction rows are not publicly redistributed pending privacy and licensing review, and the trained RoBERTa checkpoint is not included. Public checks reproduce saved-output calculations and template responses; they do not constitute independent model retraining or evidence of student learning gains.

This repository accompanies “AKC-Tutor: An Affect- and Knowledge-Aware Conversational AI Framework for Personalized Intelligent Tutoring,” by Shiva Nayak Dharavath and Raju Shanmugam. Do not add an acceptance date, journal name, DOI, license grant or ethics declaration unless verified by the authors.

## Version stability

For a submission, record a specific reviewed Git commit or release in addition to the repository homepage. After resolving licensing and privacy issues, an approved archival release can be deposited with an appropriate archive if a DOI is required. No DOI or archive deposit is asserted by this release.
