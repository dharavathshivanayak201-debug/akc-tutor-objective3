# Objective 3 / AKC-Tutor reproducibility bundle

Contains the latest available IEEE paper PDF and .tex, its inline bibliography extracted separately, original vector PDF figures, all five Colab notebooks, analysis scripts, phase result outputs, 24 scenarios and 96 generated responses, and anonymized final human evaluator workbooks.

IMPORTANT: Phase III models knowledge + behavioral proxies, NOT measured emotion + knowledge. Phase IV uses constructed scenarios and template-generated replies. Phase V scores pedagogical appropriateness, NOT actual learning gains. Rater independence is asserted by the researchers, not independently proven by these files.

Privacy: Original raw GoEmotions train/dev/test text and learner-level cleaned educational interaction table are excluded; prediction files remove public text/comment IDs and replace learner IDs with within-file pseudonyms. Original human rating notes and response text are excluded from anonymized workbooks, but full constructed response text is available in Phase IV files. Phase V PRIVATE_variant_key.csv is included for reproducibility and should NOT be distributed to evaluators before blinded assessment.

Bibliography caution: The reference-verification notes describe outstanding Q1/SCI checks. The 25 SCI-Q1 requirement has not been certified.

This is an artifact archive, not a guaranteed one-click rerun: external dataset access, training compute, checkpoints and pinned environment may be needed.
